# AutoOUTLINE
The shell script to automate installing outline on the Linux Ubuntu server

## Run:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/DaDe287/AutoOUTLINE/main/install-outline.sh)
```

v2:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/DaDe287/AutoOUTLINE/main/install-outline-v2.sh) --add-api
```
